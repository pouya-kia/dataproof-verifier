# NoUndo v0.1 semantics

For a database instance `D`, retained SQL queries `V` and scalar KPI `Q`, a witness is a pair of legal synthetic instances `D1,D2` for which every `V(D1)` and `V(D2)` is equal as an unordered multiset of typed rows and `Q(D1) != Q(D2)` under DuckDB scalar and NULL equality rules. SQL NULL compares equal to SQL NULL for result normalization, but SQL `COUNT(DISTINCT x)` omits NULL. The conclusion is limited to the declared schema and constraints; it says nothing about backups or other surviving data.

Initial input is JSON or YAML parsed with `safe_load`, with one table of explicitly typed finite-domain columns, nullable flags, optional primary and unique keys, row bound, one retained query, one scalar metric, a timeout, seed and output directory. A row is an ordered tuple; a database is a bag of rows. Source row ordering is semantically irrelevant. Candidate worlds may have zero rows. Duplicate rows remain distinct bag entries. A primary key, if present, is unique and non-NULL. SQL unique keys allow multiple rows with NULL in a keyed column. Invalid schemas are rejected before search.

Supported SQL is a deliberately guarded subset of DuckDB `SELECT`: a single named table; direct grouping by one declared column; `COUNT(*)`, `COUNT(column)`, `COUNT(DISTINCT column)`, `SUM(integer_column)`, `MIN(integer_column)`, and `MAX(integer_column)`; aliases; and a scalar aggregate metric without `GROUP BY`. Phase 3 additionally admits one row filter in either query: `WHERE integer_column = integer_literal`, `WHERE column IS NULL`, or `WHERE column IS NOT NULL`. The literal is a signed 32-bit integer; it need not occur in the declared finite domain, in which case equality matches no row. SQL NULL never satisfies `=`; `IS NULL` and `IS NOT NULL` work for INTEGER or DATE columns, including non-nullable columns. Filtering happens before grouping and aggregation. Every selected nonaggregate column must be the grouping key. No compound predicates, other comparison operators, `= NULL`, multiargument extrema, joins, arithmetic expressions, `ORDER BY`, `LIMIT`, subqueries, windows, UDFs, recursive SQL, nondeterministic functions, or writes. The parser validates the complete AST and inferred argument types; accepting SQLGlot syntax alone never establishes semantic support. DATE input values are finite ISO dates from the domain. `SUM`, `MIN`, and `MAX` on an empty input or an all-NULL group are SQL NULL; `COUNT` is zero. `MIN` and `MAX` use integer ordering over non-NULL values. Integer overflow beyond DuckDB `BIGINT` is outside the bounded domain and rejected by bounded input checks.

Result normalization records column order and typed values. View equality is `Counter(rows)` equality, preserving multiplicity; source row order and view output row order are ignored. The metric must return exactly one row and one column. NULL metrics are equal only when both NULL. No float values, approximate aggregates or collation dependent text semantics are admitted.

Statuses: `COUNTEREXAMPLE_FOUND` requires independent serialized DuckDB replay; `BOUNDED_NO_COUNTEREXAMPLE` requires complete finite search over stated bounds; `INCONCLUSIVE` covers timeout/unknown with separate exit codes 4/8 and `reason_code`; `UNSUPPORTED` covers outside-fragment SQL; malformed SQL is `INVALID_INPUT` code 6; `INVALID_CANDIDATE` covers solver/replay or constraint disagreement; `PROVEN_WITHIN_FRAGMENT` is reserved for a later sound theorem. No universal preservation claim is made by the first slice. The Phase 1 seed is recorded but the current lexicographic optimizer is deterministic without using randomness. The Z3 process memory parameter is capped by `max_memory_mb` (default 256); physical memory accounting remains platform dependent.

Soundness threats: AST nodes omitted from validation, SQL NULL and empty-set behavior, bag versus set confusion, integer overflow, constraints interpreted differently by solver and DuckDB, search timeout labeled as exhaustive, and stale/incomplete replay artifacts. Each needs a negative or independent regression check before public use.

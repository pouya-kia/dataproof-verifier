# Security reporting for the experimental Alpha

DataProof processes user-supplied local SQL specifications and synthetic artifacts. This Alpha is not production-hardened and should not be given credentials, confidential SQL, private datasets, or access to production systems.

Please report suspected vulnerabilities privately using GitHub's **Report a vulnerability** feature on this repository's Security tab. The repository's Private Vulnerability Reporting feature must be enabled and verified before the first public source push. No security email address is designated.

Do not disclose an exploitable vulnerability or sensitive reproduction in a public issue. Do not include credentials, confidential SQL, customer data, or security-sensitive details in public GitHub issues.

For ordinary, non-sensitive bugs, use [ISSUE_TEMPLATE.md](ISSUE_TEMPLATE.md) with synthetic or authorized data. Remove credentials, personally identifiable information, confidential SQL, customer rows, company infrastructure details, personal paths, and identifying metadata from logs and artifacts. Preserve the original unsupported SQL description when safe to share; do not rewrite it merely to fit the supported fragment.

No response-time or security-support commitment is made for this experimental Alpha.
